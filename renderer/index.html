📖 配置教程

获取授权码 · 申请 API Key
配好两样就能用：① QQ 邮箱 IMAP 授权码（让应用读取你的招聘邮件）+ ② 大模型 API Key（把邮件解析成日历事件）。拿到后点应用「设置」填入保存即可。

1 · 获取 QQ 邮箱 IMAP 授权码

应用通过 IMAP 只读拉取招聘邮件，需要的是授权码，不是 QQ 密码。

  1. 浏览器打开 QQ 邮箱网页版 并登录。
  2. 顶部「设置」→ 左侧「账户」。
  3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」一栏。
  4. 点「IMAP/SMTP 服务」后面的「开启」。
  5. 按提示用绑定手机发一条短信完成验证。
  6. 验证通过后页面显示 16 位授权码（形如 abcdwxyzefghijkl），复制保存好。
⚠️ 填的是「授权码」不是 QQ 密码；改了 QQ 密码后授权码通常失效，需重新生成。

2 · 申请大模型 API Key（以 DeepSeek 为例）

把邮件交给「OpenAI 兼容」模型解析。硅基流动、阿里云百炼、OpenAI 等同理。

  1. 打开 DeepSeek 开放平台 并登录。
  2. 右上角「API keys」→「创建 API key」。
  3. 复制生成的密钥（以 sk- 开头，只显示一次）。
  4. 确认账户有可用余额（DeepSeek 需先充值，新用户一般有赠送额度）。
✅ 设置里对应关系：解析服务地址填 https://api.deepseek.com/v1，解析密钥填刚复制的 sk-...，模型名填 deepseek-v4-flash。

3 · 填进设置并保存

设置项填什么
QQ 邮箱地址你的邮箱，如 123456@qq.com
IMAP 授权码第 1 步的 16 位授权码
解析服务地址https://api.deepseek.com/v1
解析密钥sk-...（第 2 步申请的 Key）
模型名deepseek-v4-flash（可改）
拉取窗口（天）45

填完点「保存」。也可先点「测试邮箱连接」「测试解析服务」验证。

✅ 配置写入项目根目录 config.json，该文件已在 .gitignore 中，不上传仓库，密钥只留本机。

4 · 常见问题

连接报 self signed certificate in certificate chain？ 网络出口有中间人代理，在 config.json 加 "tlsInsecure": true 后重启即可（仅受信任网络开启）。

授权码无效？ 确认是授权码非 QQ 密码、IMAP/SMTP 已开启、邮箱地址含 @qq.com，并可点「测试邮箱连接」看报错。

解析服务测试失败？ 确认 llmKey 以 sk- 开头无空格、llmBase 末尾带 /v1、账户有调用额度。
