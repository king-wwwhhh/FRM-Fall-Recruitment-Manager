📖 配置教程

获取 QQ 邮箱授权码 · 申请大模型 API Key
配好两样东西就能用：① QQ 邮箱 IMAP 授权码（让应用读取你的招聘邮件）+ ② 大模型 API Key（让应用把邮件解析成日历事件）。
拿到后，点应用左上角「设置」填入保存即可。下面是从零获取的步骤。

1获取 QQ 邮箱 IMAP 授权码

应用通过 IMAP 只读拉取你的招聘邮件，需要的是 授权码，不是 QQ 登录密码。

步骤

  1. 电脑浏览器打开 QQ 邮箱网页版 并登录。
  2. 点页面顶部的「设置」→ 左侧「账户」。
  3. 往下找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」这一栏。
  4. 点击「IMAP/SMTP 服务」后面的「开启」。
  5. 按页面提示，用绑定的手机发送一条短信完成验证。
  6. 验证通过后，页面会显示一串 16 位授权码（形如 abcdwxyzefghijkl），复制保存好。
⚠️ 关键提醒 这里填的是「授权码」，不是你的 QQ 密码。用 QQ 密码会登录失败。
若以后改了 QQ 密码，授权码通常会失效，需要回来重新生成。
ℹ️ 服务器参数（一般不用手填，应用已内置） IMAP 服务器：imap.qq.com ｜ 端口：993 ｜ 加密：SSL/TLS。

2申请大模型 API Key（以 DeepSeek 为例）

应用把邮件交给大模型解析成结构化事件，需要一家「OpenAI 兼容」的模型服务。下面用 DeepSeek 演示，硅基流动、阿里云百炼、OpenAI 等同理。

步骤

  1. 打开 DeepSeek 开放平台 并登录。
  2. 右上角点「API keys」→「创建 API key」。
  3. 复制生成的密钥，它以 sk- 开头（请妥善保管，只显示一次）。
  4. 确认账户有可用余额（DeepSeek 需先充值才能调用，新用户一般有赠送额度）。
✅ 填到设置里的对应关系
设置项填什么
解析服务地址 llmBasehttps://api.deepseek.com/v1
解析密钥 llmKey刚复制的 sk-... 密钥
模型名 llmModeldeepseek-v4-flash（也可换 deepseek-chat 等）
ℹ️ 用别家服务也行 只要是 OpenAI 兼容接口，把上面的 llmBase / llmKey / llmModel 换成对应值即可： 硅基流动 SiliconFlow阿里云百炼OpenAI本地 Ollama / vLLM 等。

3填进设置并保存

回到应用，点左上角「设置」，把上面两样填进去：

设置项填什么说明
QQ 邮箱地址你的邮箱如 123456@qq.com
IMAP 授权码第 1 步的 16 位授权码不是 QQ 密码
解析服务地址https://api.deepseek.com/v1OpenAI 兼容格式，末尾带 /v1
解析密钥sk-...第 2 步申请的 Key
模型名deepseek-v4-flash可改
拉取窗口（天）45拉取最近多少天的邮件
启动时自动刷新勾选打开应用即检查一次邮箱

填完点「保存」。也可先点「测试邮箱连接」「测试解析服务」验证能不能通。

✅ 配置存在哪设置写入项目根目录 config.json，该文件已在 .gitignore 中，不会上传到仓库，密钥只留在本机。

4常见问题

连接邮箱报 self signed certificate in certificate chain？

说明你的网络出口有中间人代理（公司网关 / 本地代理软件），把证书换了。在 config.json 里加一行：

"tlsInsecure": true

重启应用即可。也可设环境变量 RM_TLS_INSECURE=1。仅在受信任的本地网络开启，换到可信网络请改回 false。

授权码提示无效 / 连不上？

  1. 确认填的是「授权码」不是 QQ 密码。
  2. 确认 IMAP/SMTP 服务已「开启」。
  3. 确认邮箱地址没写错（含 @qq.com）。
  4. 点设置里的「测试邮箱连接」看具体报错。

解析服务测试失败？

  1. 确认 llmKey 以 sk- 开头、没多空格。
  2. 确认 llmBase 末尾带 /v1（OpenAI 兼容路径）。
  3. 确认账户有调用额度（DeepSeek 需充值）。
