🎯 秋招管家 · FRM

秋招投递，本地一键理清

连接 QQ 邮箱，自动把招聘邮件解析成日历事件与投递记录。
数据只在你本机，无需注册，下载即用。

⬇️ 下载 Windows 版 （ZIP）

三步开始使用（Windows）

  1. 点上方按钮下载 源码压缩包（FRM-Fall-Recruitment-Manager-main.zip）。
  2. 解压到任意文件夹，进入解压出的 FRM-Fall-Recruitment-Manager-main 目录。
  3. 双击 启动.bat：首次会自动安装依赖并启动应用，之后直接双击即可。
💡 第一次打开应用后，点右上角「设置」→「📖 配置教程」，按弹窗里的步骤填入你自己的 QQ 邮箱 IMAP 授权码 和 大模型 API Key 即可开始使用。
· 需要本机已安装 Node.js（LTS）；若没装，双击 启动.bat 时会提示去安装。
· 若双击 启动.bat 被 Windows 拦截/点了没反应：右键该文件 →「属性」→ 勾选「解除锁定」，或在拦截提示中点「仍要运行」（从网络下载的文件会被系统标记）。
· 所有邮箱凭据与数据只存在你本机，不会上传任何服务器，无需注册登录。
🔒

隐私优先，无需账号

邮箱以 IMAP 只读方式拉取，不发送、不修改、不删除任何邮件；QQ 授权码与模型密钥只存本机 config.json，代码不预置、不上传任何服务器。每个用户运行自己的独立实例，因此无需注册、无需登录鉴权。
