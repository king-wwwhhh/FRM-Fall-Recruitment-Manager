连接 QQ 邮箱，自动把招聘邮件解析成日历事件与投递记录。
数据只在你本机，无需注册，下载即用。

为什么选它

不只是"测评提醒"——覆盖招聘全流程的八类邮件，且绝不编造时间。

📥

八类邮件全识别

笔试、限时测评、面试邀约、简历完善、网申确认、offer、宣讲会、其他招聘相关，自动归一分类。

🚫

时间零推算

邮件没写时间就标注「待定」，绝不替你"收信日+3天"编一个假截止时间害你错过 DDL。

🧠

推理模型适配

针对 deepseek 等推理模型的思维链做了 token 与截断抢救，不会整批解析失败。

🕐

时区正确

统一本地时区存储与显示，已修复旧版 UTC 慢 8 小时的问题。

🔁

深度重扫

识别规则升级后用新规则重跑历史邮件，按 key+type 去重，不重复入库。

🧩

进度自动联动

笔试/测评"完成并移除"后，自动更新对应投递记录的状态。

你的数据，只留在你电脑上

这是一款本地桌面应用，不是网页后台服务。

🔒

隐私优先，无需账号

邮箱以 IMAP 只读方式拉取，不发送、不修改、不删除任何邮件；QQ 授权码与模型密钥只存本机 config.json，代码不预置、不上传任何服务器。每个用户运行自己的独立实例，因此无需注册、无需登录鉴权。

💡 首次打开后，点右上角「设置」→「📖 配置教程」，按图文步骤填入你自己的 QQ 邮箱授权码和 API Key 即可开始使用。
· macOS 用户若提示"无法验证开发者"，请右键 .dmg 选择「打开」绕过 Gatekeeper。
· Linux 用户下载 .AppImage 后执行 chmod +x 再双击运行。
